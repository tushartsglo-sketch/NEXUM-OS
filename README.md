# NEXUM

A private personal knowledge and execution system.

Capture everything useful. Connect what you learn. Turn knowledge into action.

## v0.1 foundation
Dashboard, schedule, task preview, knowledge overview, quick capture, and research threads.


## Engineering status
NEXUM is a private single-user system. Before production deployment, configure PostgreSQL and the environment variables in `.env.example`, run Prisma generation/migrations, configure VAPID keys and a protected scheduler for background reminders, and keep real secrets and personal archive data out of GitHub.
